# 📊 AI Usage and Academic Performance — Exploratory Data Analysis
**Project Overview**

This project explores the relationship between artificial intelligence (AI) usage, study behavior, learning outcomes, and academic performance among students. The analysis focuses on whether AI usage time is associated with improved study habits, conceptual understanding, or academic results.

The project is designed as an exploratory, descriptive analysis, emphasizing data validation, analytical reasoning, and transparent documentation rather than predictive modeling.

**Research Questions**

* How does AI usage relate to the number of hours students spend studying?

* Do students who use AI tools perform better academically than those who do not?

* Is AI usage associated with improved conceptual understanding and learning outcomes?

**Dataset Description**

The dataset contains student demographic information, AI usage characteristics, study habits, and academic performance indicators.

**Key variable groups:**

* Student background: age, gender, grade level

* AI usage: usage time, tools used, usage purpose, dependency score

* Study behavior: study hours, attendance, sleep hours

* Performance outcomes: final exam score, grade, improvement metrics

**Tools & Workflow**

* Google Sheets was used for data inspection, pivot-table analysis, and visualization.

* Google Docs was used for structured session-by-session documentation.

* Version history in Google Sheets was leveraged for safe iteration and transparency rather than Git-based versioning.

- This workflow prioritizes analytical clarity and reproducibility over tooling complexity.

**Methodology**

The analysis followed a structured workflow:

+ Dataset understanding and variable grouping

* Missing value inspection

* Validity and consistency checks

* Evaluation of AI-related variable reliability

* Group-based comparisons using pivot tables

* Visual support using histograms and bar charts

* Interpretation with explicit acknowledgment of dataset limitations

* No rows were removed or altered; all inconsistencies were documented and handled analytically.

**Key Findings:**

AI usage time showed no meaningful association with:

* Study hours

* Conceptual understanding

* Final academic performance

High-performing students did not study longer or use AI more than the overall population.

Conceptual understanding score was the strongest variable aligned with high academic performance.

**Visualizations**

Selected visualizations (stored in the /visuals folder) include:

* Distributions of study hours and AI usage time

* Group comparisons of understanding scores

* Performance comparisons between high scorers and overall students

Visuals were used to support descriptive insights rather than to imply causation.

**Limitations**

* Several AI-related variables are self-reported and perception-based.

* Binary AI usage indicators conflicted with continuous usage measures.

* Dependency scores and AI-generated content percentages measure different constructs.

* Conclusions are descriptive, not causal.

* These limitations were documented rather than corrected to preserve data integrity.

**Conclusion**

This project demonstrates a complete exploratory data analysis workflow, emphasizing analytical reasoning, data validation, and transparent interpretation. While AI usage time alone does not appear to improve academic outcomes in this dataset, conceptual understanding emerged as a key factor associated with strong performance.
